## About this client mod

Soar 9minecraft Client Mod gives you a brand new menu packed with tools for combat and multiplayer servers. It changes the way your screen looks by adding helpful stats, custom capes, and an easy-to-use music player. The mod also lets you join servers running older or newer versions of the game without changing your launcher. Everything is built with a smooth, modern design that makes finding and changing settings fast.

## What this is

An **unofficial** port of the original work by **CubeWhy, Eatgrapes, EldoDebug, LazyChara**, rebuilt by 9Minecraft Studios so it runs on current Minecraft releases. Not affiliated with, and not endorsed by, the original author.
